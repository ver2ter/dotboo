# Security

Do not post passwords, signing keys, private file paths, or personal logs in a
public issue. The application has no remote diagnostic collection.

For a suspected security vulnerability, use this repository's **Security →
Report a vulnerability** option if private vulnerability reporting is enabled.
If it is unavailable, open a public issue asking for a private contact channel
without disclosing the vulnerability or sensitive details.

Only the latest published version is maintained. Reports should identify the
version, macOS version, and reproduction steps, shared through a private channel.

Changing Finder visibility does not change file access permissions or protect
confidential data. Download application archives from the official repository's
Releases section and compare their SHA-256 checksums when provided.
