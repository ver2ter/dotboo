# DotBoo visual identity

The approved mark is an outlined black ghost on ivory, with one open eye and
one winking eye. The application name is DotBoo; the repository name is dotboo.

`Resources/Branding/DotBoo.png` is the shared source for the README logo and the
macOS application icon. `Tools/GenerateIcons.swift` renders the required icon
sizes from this source, with a rounded macOS tile and transparent outer margin.
The menu bar retains its eye/eye-slash state indicators for Finder visibility.

The source artwork was generated with the built-in imagegen tool and selected
by the project owner. The final editing instruction was to preserve the outlined
ghost and ivory background, replacing the single eye with an open oval eye on
the left and a curved closed eye on the right, with no mouth or extra decoration.
